# Armature Transfer

素体側 Armature の Transform（Position / Rotation / Scale）、汎用コンポーネント、VRC PhysBone（Collider含む）、不足オブジェクトを衣装側 Armature の同名ボーンへ一括コピーします。

- **メニュー**: `Tools > Cocoa's Toolbox > Armature Transfer`
