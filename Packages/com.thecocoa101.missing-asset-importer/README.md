# Missing Asset Importer

Migrate先のプロジェクトにて、元プロジェクトフォルダと Missing になっている Prefab をセットして `GET` ボタンを押すだけで、不足アセットと依存ファイルだけを GUID を維持したまま `.unitypackage` 化してインポートします。

- **メニュー**: `Tools > Cocoa's Toolbox > Missing Asset Importer`
