# Animation Path Adjuster

複数の `.anim` ファイル（またはフォルダ・AnimatorController）をまとめて登録してパスを一括変更したり、1つの `.anim` 内の個別要素を複数選択してパスを書き換えられます。

- **メニュー**: `Tools > Cocoa's Toolbox > Animation Path Adjuster` / Project 右クリック `Cocoa's Toolbox`
