# Skinned To Static Mesh

ボーン変形や BlendShape 変形後の SkinnedMeshRenderer を、見た目上の位置・形状を維持したまま StaticMesh（MeshFilter + MeshRenderer / `.mesh`）へ変換・結合します。

- **メニュー**: `Tools > Cocoa's Toolbox > Skinned To Static Mesh` / Hierarchy 右クリック `Cocoa's Toolbox`
