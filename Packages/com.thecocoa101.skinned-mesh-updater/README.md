# Skinned Mesh Updater

外部ツールで編集・再エクスポートしたメッシュを既存の SkinnedMeshRenderer に置き換える際、座標軸・スケール・原点オフセット・ボーン順・バインドポーズズレを Unity 側のみで自動補正します。

- **メニュー**: `Tools > Cocoa's Toolbox > Skinned Mesh Updater` / Hierarchy・SkinnedMeshRenderer 右クリック
