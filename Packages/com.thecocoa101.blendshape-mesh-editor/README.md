# Blendshape Mesh Editor

SkinnedMeshRenderer に対して SceneView 上で頂点・辺・面・アイランドを選択してプロポーショナル編集やギズモ・ブラシで変形し、差分を新しい BlendShape として追加した `.mesh` アセットを新規保存します。

- **メニュー**: `Tools > Cocoa's Toolbox > Blendshape Mesh Editor` / Hierarchy・SkinnedMeshRenderer 右クリック
