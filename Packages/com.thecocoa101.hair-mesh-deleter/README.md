# Hair Mesh Deleter

髪メッシュの房（アイランド）を SceneView 上でクリック選択し、リアルタイムに削除プレビュー確認しながらウェイト・BlendShape・全UVを維持した新しい `.mesh` アセットとして非破壊保存します。

- **メニュー**: `Tools > Cocoa's Toolbox > Hair Mesh Deleter` / Hierarchy 右クリック `Cocoa's Toolbox`
