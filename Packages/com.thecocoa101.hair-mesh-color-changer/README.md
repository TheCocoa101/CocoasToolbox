# Hair Mesh Color Changer

髪メッシュの房（アイランド）を SceneView 上でクリック選択し、基本色彩調整スライダー（色相・彩度・明度・コントラスト）での部分色変更や lilToon 用マスクテクスチャ生成・自動設定を行います。

- **メニュー**: `Tools > Cocoa's Toolbox > Hair Mesh Color Changer` / Hierarchy 右クリック `Cocoa's Toolbox`
